[ How to use ? ]
[QUICK SEARCH]
  1. Enter a keyword to the top-field.
  2. To add keywords, select [Add keyword] and enter keyword. 
  3. Select the search engine.

[EXPERT SEARCH]
  If you want to use expert-search, select [Link] or clear keyword-fields and select the site.

[ASCII TRANSLATION]
  When [ASCII] is checked, keywords are submitted in ASCII codes.
  If it has any problems, uncheck [ASCII].

[SEARCH TIPS...]
  - No title found. -
    Use more general word or simplify the keyword.
     ex) mass pshyology  >>  pshyology

  - Too much title found. -
    Add keywords.
     ex) driver  >>  driver [AND] car [NOT] tool

  - Too much useless result. -
    Find link page and trace the link, or change keyword.
